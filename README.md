# ДЗ 1 — Steel Plates Faults

Выбран датасет из списка задания: дефекты стальных пластин, 1941 наблюдение, 27 признаков и 7 классов. Он достаточно небольшой для нескольких экспериментов, при этом есть дисбаланс и связанные измерения.

Источник: [UCI Steel Plates Faults](https://archive.ics.uci.edu/dataset/198/steel+plates+faults). DOI: [10.24432/C5J88N](https://doi.org/10.24432/C5J88N). Исходные `Faults.NNA` и `Faults27x7_var` лежат в `data/`. Данные UCI распространяются по CC BY 4.0; авторы набора — M. Buscema, S. Terzi, W. Tastle.

## Исходные гипотезы

1. У константного прогноза самого частого класса accuracy превысит macro F1 хотя бы на 0.15 из-за дисбаланса.
2. Масштабирование улучшит средний CV macro F1 логистической регрессии хотя бы на 0.02.
3. Подобранный случайный лес обойдёт подобранную логистическую регрессию по CV macro F1 хотя бы на 0.03: зависимости могут быть нелинейными.
4. У дерева без ограничения глубины разрыв train–CV macro F1 будет больше 0.10 и больше, чем у дерева глубины 5.
5. `class_weight='balanced'` улучшит CV macro F1 логистической регрессии хотя бы на 0.01 при одинаковом C=1.
6. Отбор 15 признаков через ANOVA снизит CV macro F1 масштабированной логистической регрессии не больше чем на 0.02 (C=1 в обоих случаях).

## Что получилось

1. Подтвердилась по заданному критерию. Dummy: accuracy=0.347, macro F1=0.074. Частый класс даёт заметную accuracy, но остальные классы теряются.
2. Подтвердилась по заданному критерию. Macro F1 без масштаба 0.352, с масштабом 0.702; разница +0.350. Масштаб меняет действие регуляризации на признаки.
3. Подтвердилась по заданному критерию. Лес 0.802, LogReg 0.712. Разница согласуется с пользой нелинейных разбиений, но не доказывает причину.
4. Подтвердилась по заданному критерию. Разрыв train–CV: полное дерево 0.286, глубина 5 — 0.032. Запоминание train не равно качеству на новых данных.
5. Не подтвердилась по заданному критерию. С весами 0.669, без весов 0.702. Взвешивание меняет компромисс ошибок, поэтому улучшение не гарантировано.
6. Не подтвердилась по заданному критерию. 15 признаков: 0.559; все: 0.702. ANOVA смотрит на каждый признак отдельно и может потерять полезные совместные связи.

Основная метрика — macro F1. Выбор модели и параметров сделан по пятифолдовой стратифицированной CV на 75% данных; 25% оставлены на финальный тест. Seed 42. Преобразования и отбор признаков обучаются внутри фолдов. Семь столбцов меток исключены из X.

Результаты на тесте:

| Модель | Accuracy | Macro F1 | Balanced accuracy |
|---|---:|---:|---:|
| dummy | 0.346 | 0.073 | 0.143 |
| logreg | 0.730 | 0.735 | 0.717 |
| tree | 0.747 | 0.752 | 0.733 |
| forest | 0.794 | 0.804 | 0.787 |

По CV выбран случайный лес. Его тестовый macro F1 — 0.804, bootstrap-интервал примерно [0.758; 0.841]. Для редких классов оценка менее устойчива. Ограничение дерева до глубины 5 уменьшило разрыв train–CV, но ухудшило CV качество: это пример недообучения. Веса классов повысили средний recall, но снизили F1. Отбор ANOVA оказался слишком грубым для этой задачи.

Случайное разбиение не проверяет перенос на новые линии производства: групповых идентификаторов в наборе нет. Bootstrap не учитывает изменение обучающей выборки. Гипотезы проверены по заранее заданным практическим порогам, без заявления статистической значимости.

## Запуск

Python 3.13. Из этой папки:

```bash
python -m pip install -r requirements.txt
python -m jupyter notebook research.ipynb
```

Далее Run All. Интернет для расчётов не требуется. Ноутбук уже выполнен, таблицы и графики сохранены внутри. Подбор леса занимает несколько минут на CPU.

* `research.ipynb` — анализ, эксперименты, графики и выводы.
* `data/` — исходный датасет.
* `results/` — таблицы CV, подбора и теста, выводы в JSON.
* `requirements.txt` — зависимости.

Папка подготовлена для размещения в GitHub-репозитории. Публикация и отправка ссылки преподавателю здесь не выполнялись.
